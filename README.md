# Bank-Customer-Behavior-Churn
This Bank Customer Churn Analysis project focuses on identifying customer retention patterns and factors contributing to churn in the banking sector.
The dataset includes customer attributes such as credit score, country, gender, age, tenure, account balance, credit card ownership, active membership status, salary, and churn information.
Data cleaning, preprocessing, and handling of missing values were performed using Python to ensure data accuracy and consistency for analysis.
SQL was used to generate meaningful business insights by analyzing customer behavior, churn trends, demographic patterns, and financial characteristics.
An interactive Tableau dashboard was developed to visualize key KPIs, customer segmentation, churn distribution, and overall business performance.
The project supports data-driven decision-making by helping businesses understand customer attrition and improve customer retention strategies.
